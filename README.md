# Customer Shopping Behavior Analysis

## Project Overview
This project focuses on analyzing customer shopping behavior to understand purchasing patterns, sales performance, customer preferences, and subscription trends. The analysis helps identify meaningful business insights from customer transaction data.

## Tools & Technologies
- Python
- Pandas
- SQL
- MySQL
- MySQL Connector
- Power BI
- Google Colab

## Project Workflow

1. **Data Cleaning:** Cleaned the dataset using Python and Pandas, handled missing values, and standardized column names.
2. **Exploratory Data Analysis (EDA):** Explored customer demographics, purchasing patterns, product preferences, and sales trends.
3. **Feature Engineering:** Created age groups and purchase frequency features.
4. **SQL Analysis:** Used MySQL queries to analyze customer spending, revenue, product ratings, discounts, and subscription behavior.
5. **Data Visualization:** Created an interactive Power BI dashboard to present key findings.

## Business Questions
- What is the revenue generated by gender?
- Which products have the highest customer ratings?
- How do discounts affect customer spending?
- Do subscribers spend differently from non-subscribers?
- Which product categories generate more revenue?
- What are the purchasing patterns of different age groups?
- Who are the repeat customers?

## Key Outcomes
- Analyzed customer purchasing patterns and spending behavior.
- Identified product performance and customer preferences.
- Explored the relationship between discounts and customer spending.
- Presented business insights through data visualization.

## Repository Structure
